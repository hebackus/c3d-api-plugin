# Developer's Guide Organization (.NET)

This guide provides information on how to use the AutoCAD .NET API with Microsoft Visual Studio and the programming languages C# and VB.NET. Information specific to developing applications using Microsoft Visual Studio can be found under the topics “Getting Started with Microsoft Visual Studio” and “Develop Applications with C# or VB.NET.”
